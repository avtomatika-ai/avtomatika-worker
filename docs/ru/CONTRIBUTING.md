# Участие в разработке Avtomatika Worker SDK

Спасибо, что помогаете улучшать нашу экосистему!

## Настройка

1. Клонируйте репозиторий и перейдите в его корень.
2. Установите зависимости для разработки:
   ```bash
   pip install -e .[dev]
   ```

## Контроль качества

Мы используем `ruff` для линтинга и форматирования, а также `mypy` для проверки типизации. Пожалуйста, убедитесь, что ваши изменения проходят эти проверки:

```bash
# Линтинг и форматирование
ruff check .
ruff format .

# Проверка типизации
mypy src/avtomatika_worker
```

## Тестирование

Запустите тесты воркера:

```bash
pytest
```

## Добавление новых функций

- Если вы добавляете новый параметр конфигурации, обновите `src/avtomatika_worker/config.py`.
- Если вы меняете логику взаимодействия по протоколу, убедитесь в совместимости с пакетом `rxon`.
- Всегда обновляйте `README.md`, если меняется публичное API.
- Весь новый код должен иметь аннотации типов.
