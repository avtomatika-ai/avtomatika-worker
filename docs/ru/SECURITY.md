# Политика безопасности

## Сообщения об уязвимостях

Если вы обнаружили потенциальную уязвимость в Worker SDK, пожалуйста, не открывайте публичное Issue. Вместо этого отправьте письмо на адрес [madgagarin@gmail.com].

## Модель безопасности

Являясь фундаментальной частью экосистемы HLN, Worker SDK реализует:
- **Поддержка mTLS**: Автоматическая обработка клиентских сертификатов.
- **Ротация токенов**: Встроенная логика обновления STS-токенов.
- **Изолированные рабочие области**: Изоляция файловой системы для каждой задачи для предотвращения утечки данных между ними.

Смотрите полную [Модель безопасности HLN](../../packages/hln/SECURITY.md) для получения подробной информации.
